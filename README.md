# doncantow.com

Static copy of Don Cantow's Squarespace site (doncantow.com), moved to GitHub Pages.

- Every page, post, quote and image from the Squarespace site, at the same addresses (`/sales-value`, `/blog/2017/7/10/trust`, ...).
- Squarespace's scripts are gone; `assets/static-copy.js` does the phone menu and folder links.
- Squarespace's Adobe fonts can't move with the site; `assets/static-copy.css` maps free look-alikes (EB Garamond, Montserrat) onto the same font names.
